# Software Architect — folder index

Per [`CLAUDE.md`](../../../CLAUDE.md) §1 every folder under the repo
root carries a `README.md`. This file points at the entries a fresh
session reads.

- **[`AGENT.md`](AGENT.md)** — role definition, mission, required
  reading order. Read this first.
- **[`STATUS.md`](STATUS.md)** — current sprint snapshot from the
  last session's hand-off.
- **[`NEXT_STEPS.md`](NEXT_STEPS.md)** — Architect's working queue
  ordered by priority.
- **[`DECISIONS.md`](DECISIONS.md)** — append-only log of
  Architect-lane decisions.
- **[`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md)** — questions awaiting
  a decision.
- **[`SKILLS.md`](SKILLS.md)** — repeatable techniques and patterns
  the lane has codified.
