# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** verbatim, by reference. The canonical text is the authoritative version; this file states the **scope, enforcement contact, and timeline** for *django-admin-react*.

## Scope

The Code of Conduct applies in every project space — this repository's Issues, Pull Requests, Discussions, and commit messages; the project's GitHub Releases page; the sibling repositories ([`django-admin-rest-api`](https://github.com/MartinCastroAlvarez/django-admin-api), [`django-admin-mcp`](https://github.com/MartinCastroAlvarez/django-admin-mcp)); and any public space where someone is officially representing the project.

It applies equally to humans and to AI agents that author commits, reviews, or comments on behalf of a human contributor. See [`CLAUDE.md`](CLAUDE.md) for the contract that governs AI agents working in this repo.

## Reporting

Mirror the reporting path defined in [`SECURITY.md`](SECURITY.md) §1, so reporters have a single, stable channel and there is no hardcoded contact that can expire:

1. **Preferred — private channel on GitHub.** Use **[Security → Advisories → New draft advisory](https://github.com/MartinCastroAlvarez/django-admin-react/security/advisories/new)** on this repository. It is private end-to-end between the reporter and the maintainers and produces a published advisory at fix-time without re-keying.
2. **Fallback** — if a GitHub Security Advisory is not viable for the reporter (no GitHub account, or the issue blocks repo access), contact the project maintainer directly via the email listed on their public GitHub profile and request a private channel.

Reports are acknowledged within **5 working days**. Action follows the Enforcement Guidelines in the Contributor Covenant 2.1 (correction → warning → temporary ban → permanent ban, scaled to the conduct).

## Enforcement

Project maintainers are responsible for clarifying and enforcing the standards described in the Contributor Covenant 2.1 and will take appropriate, fair corrective action in response to any behavior they consider inappropriate, threatening, offensive, or harmful — including removing, editing, or rejecting comments, commits, code, issues, and other contributions, and temporarily or permanently banning any contributor for behavior they deem inappropriate.
